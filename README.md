# Hemalatha's Portfolio

A personal portfolio website introducing Hemalatha and showcasing her interests and developing web-development skills.

## Live Website

Visit the portfolio at [yallasirihemasri5.github.io](https://yallasirihemasri5.github.io/).

## Features

- Introduction and profile photo
- About Me and Skills sections
- Portfolio project showcase
- Links to LinkedIn and GitHub
- Contact email link
- Responsive layout for desktop and mobile screens
- Footer year that updates automatically

## Built With

- HTML
- CSS
- JavaScript

## Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/yallasirihemasri5/yallasirihemasri5.github.io.git
   ```

2. Open the repository folder and launch `index.html` in a web browser. You can also open the folder in Visual Studio Code and use a local preview extension.

## Project Files

- `index.html` - portfolio content and page structure
- `style.css` - layout, colors, and responsive styling
- `script.js` - updates the footer year
- `profile.png` - profile photo used on the home section
